# MyGolfCourse

Public web build of SimGolf, a Sim Golf style course builder. Paint terrain, place tees and cups, and watch the funds and par change.

Play it at https://meadam35.github.io/MyGolfCourse/

Questions, ideas, and bug reports are welcome in **Discussions**.

This repo only holds the published build. The source lives in a private repo, and the build is pushed here by its GitHub Pages workflow.
